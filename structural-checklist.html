About this app

Structural Checklist reads the Structural work orders report from Smartsheet (via the Cloudflare proxy), lists every production file attached to a job, and lets you count off marks as they're fabricated. Cut length sheets open as a tappable list; every other PDF opens as drawings with a counter on each page. Saving progress uploads a marked-up "IN PROGRESS" copy of each file you touched back to the job's row.

Known limitations

• Cover Page, Pack Label and Mapping attachments are hidden. Any file with "Cut Length" in its name opens as a list; everything else opens as drawings.

• Uploads made by this app all show as authored by whichever Smartsheet account the proxy's token belongs to, not the tablet's user.

• Files over 30MB can't be uploaded via the API (Smartsheet's limit).
